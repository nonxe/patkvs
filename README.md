# PAT KVS Educational Portal - Physical Education & Employability Skills

An educational web application built for Class XII-A, XII-B, XI-A, and XI-B students of KVS preparing for their Physical Education & Employability Skills examinations.

## 📢 Urgent Exam Notice
> **Notice for Tomorrow's Exam:**
> The syllabus for **Class XII-A, XII-B, XI-A, and XI-B is IDENTICAL**.
> Tomorrow's examination covers:
> 1. **UNIT 1: ASSESSMENT OF STUDENTS** (from Physical Activity Trainer XII)
> 2. **COMMUNICATION SKILLS** (from Employability Skills XII)

## ✨ Features
- 📖 **Embedded PDF Reader**: View `Physical_Activity_Trainer_XII.PDF` and `Employability_Skills_XII.PDF` directly inside the browser.
- 📥 **Direct PDF Downloads**: 1-click download buttons for offline study.
- 💡 **High-Yield Revision Notes**: Key formulas (BMI, Kraus-Weber Test, 7 Cs of Communication, Posture Assessment).
- ✍️ **Interactive Practice Quiz**: Instant self-assessment quiz with detailed explanations.
- 📱 **Mobile Responsive & Dark Mode**: Glassmorphic UI with vibrant dark mode aesthetic.
